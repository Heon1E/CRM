# 브랜드 서체

회사 e카탈로그(`IND_eCatalog_2026.pdf`)에서 실제로 쓰인 서체다. 규격은 `DESIGN.md`.

| 파일 | 서체 | 출처 | 라이선스 |
|---|---|---|---|
| `NanumSquareNeo-400/700/800.woff2` | 나눔스퀘어 네오 | 네이버 | 나눔글꼴 라이선스 — 자유 이용·재배포 허용 |
| `Montserrat-var.woff2` | Montserrat (가변, 라틴만) | Google Fonts | SIL Open Font License 1.1 |

**CDN을 쓰지 않고 직접 담는다.** 외부에서 받아오면 인쇄하는 순간 글꼴이 안 와서
견적서가 다른 모양으로 나갈 수 있다. 고객에게 가는 문서라 그러면 안 된다.

나눔스퀘어 네오는 굵기별 파일이라 400/700/800 셋만 담았다. 카탈로그의
Light(300)는 400으로 대체한다 — 파일 하나(380KB)를 더 받을 값어치가 없다.
Montserrat는 가변 폰트 하나(37KB)가 100~900을 전부 덮는다.
