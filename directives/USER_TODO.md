## 2. 🔴 Vercel 환경변수 — 텔레그램 봇·아침 브리핑이 멈춰 있습니다

`api/telegram-webhook.js`와 `api/daily-digest.js`는 RLS를 우회해야 하므로
서비스 롤 키가 필요합니다. 없으면 **아무 응답도 못 합니다.**

> Vercel → 프로젝트 → **Settings** → **Environment Variables** → 추가
>
> ```
> 이름 : SUPABASE_SERVICE_ROLE_KEY
> 값   : Supabase → Project Settings → API → service_role 의 값
> ```
>
> **`VITE_` 를 붙이면 안 됩니다.** 붙이면 브라우저 번들에 박혀 공개됩니다.

넣으신 뒤 재배포(Redeploy)해야 반영됩니다.

## 4. 🟢 카카오 지도 키 받기 (5분, 카드 등록 없음)

**구글 지도를 카카오로 바꿨습니다.** 결제 때문에 쓰지 못하던 지도를 무료로 씁니다.

| | 구글 | 네이버(NCP) | **카카오** |
|---|---|---|---|
| 결제수단 등록 | **필수** | **필수** | **불필요** |
| 무료 지도 | — | — | **30만 건/일** |
| 무료 주소→좌표 | — | — | **10만 건/일** |

거래처가 1,150곳이고 지도는 가끔 여는 화면이라 무료 범위 근처에도 못 갑니다.

> 1. **developers.kakao.com** 로그인 → 내 애플리케이션 → **애플리케이션 추가**
> 2. 앱 설정 → **플랫폼** → **Web 등록**에 두 주소를 모두 넣기
>    ```
>    http://localhost:5173
>    https://crm-dashboard-blush.vercel.app
>    ```
> 3. **앱 키** 화면에서 **JavaScript 키** 복사
> 4. `.env` 파일에 한 줄 추가 → dev 서버 재시작
>    ```
>    VITE_KAKAO_MAP_KEY=복사한값
>    ```
> 5. 배포에도 쓰려면 **Vercel 환경변수**에 같은 이름으로 추가

키를 넣기 전까지 `/map` 화면이 위 절차를 그대로 안내합니다.
좌표는 이미 **26곳**에 저장돼 있어 키만 넣으면 즉시 보입니다.

**구글 클라우드 결제는 이제 하지 않으셔도 됩니다.**
